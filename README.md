# secnote

パスワードで暗号化して保存する、ターミナル用のテキストエディターです。
Go 製で、Linux / macOS / Windows で同じように動きます (cgo 不要、単一バイナリ)。

- ファイルを開くときにパスワードを入力し、上書き保存ではそのパスワードをそのまま使います
- 新しいファイルに保存するとき (初回保存・名前を付けて保存) は、パスワードを 2 回入力して決めます
- 操作感は Microsoft Edit 相当: メニュー、マウス、検索/置換、折り返し、複数ドキュメント、元に戻す/やり直し
- 文字コードは UTF-8 のみ。全角文字・絵文字・結合文字を 1 文字として扱います
- ファイル形式は [age](https://age-encryption.org/) 互換。secnote がなくても `age -d` で復号できます

## ビルド

Go 1.25 以降が必要です。

```bash
go build -o secnote .
```

Linux / Windows / macOS の amd64・arm64 向けをまとめてビルドするには `build.sh` を使います。
`dist/` に `secnote-<バージョン>-<OS>-<ARCH>` という名前のバイナリと `SHA256SUMS` ができます。

```bash
./build.sh
```

ターゲットを絞る、バージョンや出力先を変える、といった指定もできます (`./build.sh -h` で一覧)。

```bash
VERSION=1.2.0 OUT=release ./build.sh windows/amd64 linux/arm64
```

## 使い方

```bash
./secnote [オプション] [ファイル ...]
```

| オプション | 意味 |
| --- | --- |
| `-nowrap` | 右端で折り返さない (既定は折り返す) |
| `-tabs` | インデントにタブ文字を使う (既定はスペース) |
| `-tabwidth N` | タブ幅 (既定 4) |
| `-version` | バージョンを表示 |

存在しないファイル名を指定すると、その名前で保存される空のドキュメントが開きます。

### パスワードの扱い

| 操作 | パスワード |
| --- | --- |
| 暗号化ファイルを開く | 入力を求める。違っていれば再入力 |
| 上書き保存 (Ctrl+S) | 開いたとき (または最後に決めたとき) のものをそのまま使う |
| 初回の保存 / 名前を付けて保存 | 新しいパスワードを 2 回入力して決める |

パスワードを変えたいときは「名前を付けて保存」で同じファイルを選び、新しいパスワードを入力します。

暗号化されていない UTF-8 テキストも開けます (ステータスバーに「平文」と表示)。
これを保存すると、元のファイルは書き換えずに `元の名前.age` という暗号化ファイルを別に作ります。
平文の元ファイルは残るので、不要なら自分で削除してください。

### キー操作

| キー | 動作 |
| --- | --- |
| Ctrl+N / Ctrl+O | 新規 / 開く |
| Ctrl+S | 上書き保存 |
| Ctrl+W / Ctrl+Q | 閉じる / 終了 |
| Ctrl+P | 開いているドキュメントの一覧 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+X / Ctrl+C / Ctrl+V | 切り取り / コピー / 貼り付け |
| Ctrl+A | すべて選択 |
| Ctrl+F / Ctrl+R | 検索 / 置換 |
| F3 / Shift+F3 | 次を検索 / 前を検索 |
| Ctrl+G | 行へ移動 |
| Shift+矢印 など | 選択範囲を広げる |
| Ctrl+Left / Ctrl+Right | 単語単位で移動 (日本語は字種の変わり目で止まる) |
| Ctrl+Home / Ctrl+End | 文頭 / 文末 |
| Ctrl+Up / Ctrl+Down | カーソルを動かさずにスクロール |
| Tab / Shift+Tab | インデント / インデント解除 (複数行選択時は行ごと) |
| Alt+Z | 右端で折り返す の切り替え |
| F10、Alt+F / E / V / H | メニュー |

検索バーでは Alt+C (大文字小文字の区別)、Alt+W (単語単位)、Alt+R (正規表現)、
Alt+A (すべて置換) が使えます。正規表現は Go の `regexp` (RE2) の書式で、置換文字列では `$1` でグループを参照できます。

マウスでは、クリックでカーソル移動、ドラッグで選択、ダブルクリックで単語選択、トリプルクリックで行選択、
ホイールでスクロールができます。ステータスバーの「行, 列」「スペース/タブ」「LF/CRLF」もクリックできます。

## ファイル形式

保存されるファイルは age v1 形式 (バイナリ) で、受信者は scrypt パスフレーズ 1 つです。

- 鍵導出: scrypt (N = 2^18)、ファイルごとにランダムな salt
- 暗号化: ChaCha20-Poly1305 (64 KiB チャンクごとに認証)

独自の暗号形式は使っていないので、標準の age コマンドでも読み書きできます。

```bash
age -d memo.age
```

拡張子は自由ですが、`.age` を付けておくと分かりやすくなります。

保存は「同じフォルダーの一時ファイルに書き出してからリネーム」で行うので、
保存中に落ちても元のファイルが壊れることはありません。新規ファイルのパーミッションは `0600` です。

## セキュリティ上の注意

- **パスワードを忘れると復号できません。** 復旧手段はありません。
- 平文とパスワードは、ドキュメントを開いている間プロセスのメモリ上にあります。
  Go のランタイムではメモリの確実な消去ができないため、メモリを読める攻撃者 (同じユーザー権限のマルウェア、スワップやコアダンプの解析) からは守れません。
- 平文をディスクに書くことはありません (バックアップ、スワップファイル、一時ファイルは作りません)。
  代わりに、保存せずに異常終了した編集内容は失われます。
- コピー / 切り取りした内容は OS のクリップボードに入ります。クリップボード履歴ツールを使っている場合は注意してください。
- 暗号の強度はパスワードの強度で決まります。scrypt が総当たりを遅くしますが、短い・ありがちなパスワードは破られます。

## 制限

- 文字コードは UTF-8 のみです。それ以外のファイルは開かずにエラーにします。BOM は読み込み時に取り除きます。
- 開けるファイルは 64 MiB までです (全体をメモリに読み込みます)。
- 検索は行単位です。改行をまたぐパターンには一致しません。
- 折り返し・タブ幅などの設定は保存されません。起動オプションで指定してください。
- Linux でシステムのクリップボードを使うには `xclip`、`xsel`、`wl-clipboard` のいずれかが必要です。
  無い場合はエディター内だけのクリップボードになり、コピー時には OSC 52 で端末にも渡します。
- macOS のターミナルでは、Option キーを Meta として送る設定にしないと Alt+ のショートカットが届きません。メニューは F10 でも開けます。

## Windows での注意

- **Microsoft Defender の誤検知**: Go で作った exe は Defender に誤検知されることがあります
  (実例: `Trojan:Win32/Bearfoos.A!ml`。末尾の `!ml` は機械学習による推定を表します)。
  一度検知されたファイルは、コピーしただけで削除されるようになります。
  自分の PC で使うだけなら「Windows セキュリティ → 保護の履歴」から許可できます。
  配布する場合は [Microsoft への誤検知の提出](https://www.microsoft.com/en-us/wdsi/filesubmission) かコード署名が必要です。
- **絵文字などの入力**: 端末によっては、絵文字や「𠮷」のような一部の漢字 (Unicode の基本多言語面の外にある文字) を
  入力・貼り付けしても文字が入りません。使用しているライブラリ tcell の不具合で、SSH 経由の端末で確認しています。
  ファイルに既に含まれている文字の表示と保存には影響しません。
- ファイル選択の一覧には、エクスプローラーが隠すシステムファイル (`pagefile.sys` など) を出しません。
